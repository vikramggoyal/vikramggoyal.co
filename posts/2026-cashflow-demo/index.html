Poking at a level-premium cashflow

A toy but not-embarrassing projection: expected cashflows for a single-life, level-premium term policy. Everything runs at build time — the chart below is static Plotly HTML baked into the page, so there’s no runtime and it stays on free static hosting. (When a reader actually needs to change inputs and re-run, that’s when Quarto Live / Shinylive earn their weight — not here.)

The mortality basis is a Gompertz law, purely so the post is self-contained; swap in a real table when you want.

import numpy as np
import pandas as pd
import plotly.graph_objects as go

# --- Assumptions -----------------------------------------------------------
issue_age   = 45
term        = 20          # years
sum_assured = 250_000
i           = 0.04        # valuation rate
# Gompertz mu(x) = B c^x, chosen to give sensible adult mortality
B, c        = 3.0e-5, 1.09

# --- Survival / mortality --------------------------------------------------
ages = issue_age + np.arange(term)
# integrate mu over each policy year for a one-year death probability
def qx(age):
    # ∫ B c^s ds from age to age+1  =  B (c^{age+1} - c^{age}) / ln c
    Hx = B * (c**(age + 1) - c**age) / np.log(c)
    return 1 - np.exp(-Hx)

q = np.array([qx(a) for a in ages])
p = 1 - q
tpx = np.concatenate(([1.0], np.cumprod(p)))[:term]   # prob in force at start of yr

# --- Level net premium (equivalence principle) ----------------------------
v = 1 / (1 + i)
disc_start = v ** np.arange(term)          # discount to start of each year
disc_end   = v ** (np.arange(term) + 1)

apv_benefits = np.sum(sum_assured * tpx * q * disc_end)      # death benefit APV
annuity_due  = np.sum(tpx * disc_start)                      # ä for premiums
net_premium  = apv_benefits / annuity_due

# --- Expected cashflows per year -------------------------------------------
prem_in   = net_premium * tpx                 # collected while in force
claims_out = sum_assured * tpx * q            # expected death outgo
net_cf     = prem_in - claims_out

df = pd.DataFrame({
    "policy_year": np.arange(1, term + 1),
    "premium_in": prem_in,
    "claims_out": claims_out,
    "net_cashflow": net_cf,
})

Net level premium comes out at 824 per year for a 250,000 benefit.

fig = go.Figure()
fig.add_bar(x=df.policy_year, y=df.premium_in,  name="Premium in")
fig.add_bar(x=df.policy_year, y=-df.claims_out, name="Claims out")
fig.add_scatter(x=df.policy_year, y=df.net_cashflow, name="Net cashflow",
                mode="lines+markers", line=dict(width=3))

fig.update_layout(
    barmode="relative",
    template="plotly_white",
    xaxis_title="Policy year",
    yaxis_title="Expected cashflow",
    legend=dict(orientation="h", y=1.12),
    margin=dict(l=40, r=20, t=30, b=40),
    height=430,
)
fig.show()

The net cashflow is positive early (premiums outrun expected claims while mortality is light) and turns down as the insured ages — the usual shape, and the reason the early-duration surplus has to be reserved rather than spent.
